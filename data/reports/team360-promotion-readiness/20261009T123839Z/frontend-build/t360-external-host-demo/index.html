External Host Demo

Host externo controlado para el Diagnosticador

Esta página simula un sitio anfitrión separado que monta el embed con `client_id`, auth server-side y sesión aislada.

Contrato público mínimo

  • clientId: identificador público del embed.
  • apiBaseUrl: endpoint público del backend.
  • sessionStorageKey: namespace aislado por host.
  • assistantName y compact: solo visual.

El host no conoce tenant, scope ni secretos. La firma por turno se obtiene vía /api/diagnosis/embed/auth.

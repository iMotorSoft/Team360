Browser Asset Demo

Host controlado con asset JS real servido por Astro

Esta página carga un asset browser estable mediante <script type="module" src="/embed/team360-diagnosticador.js"> y luego monta el Diagnosticador desde window.Team360Diagnosticador.

Contrato del asset

  • URL estable: /embed/team360-diagnosticador.js
  • Global expuesto: window.Team360Diagnosticador
  • Montaje: mount(container, config)
  • Session key: team360.embed.asset.demo.session.v1

El asset no contiene config de demo. Solo registra el global y delega en el adapter existente. La firma server-side sigue pasando por /api/diagnosis/embed/auth y /api/diagnosis/turn.

<div id="team360-asset-target"></div>
<script type="module" src="/embed/team360-diagnosticador.js"></script>
<script type="module">
  window.Team360Diagnosticador.mount('#team360-asset-target', {
    clientId: 'local_embed_demo',
    apiBaseUrl: 'http://127.0.0.1:7050/api',
    sessionStorageKey: 'team360.embed.asset.demo.session.v1'
  });
</script>

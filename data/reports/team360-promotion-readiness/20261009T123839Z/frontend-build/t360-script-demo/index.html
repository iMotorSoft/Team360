Browser Global Demo

Host controlado con `window.Team360Diagnosticador.mount()`

Esta página simula un host que registra un script global experimental y monta el Diagnosticador desde un contenedor visible, sin exponer tenant, scope ni secretos.

Contrato global experimental

  • window.Team360Diagnosticador.mount(container, config)
  • clientId y apiBaseUrl como contrato seguro mínimo.
  • sessionStorageKey aislada para este host por script.
  • destroy() disponible vía handle retornado por `mount()`.

El script global reusa el adapter interno de Fase 9B. La firma server-side sigue pasando por /api/diagnosis/embed/auth y luego por /api/diagnosis/turn.
